The study restores A2 through two off-pad L1–L4 drills with 0.15 mm holes and 0.30 mm lands. Signal current travels between L1 and L3. The 36.83124 mm planar route meets the 36.14999–38.68999 mm command project window. Modeled flight is 262.838 ps, or +20.841 ps relative to the clock pair mean. The model does not extract discontinuities or prove receiver setup/hold.

Against the populated board, the bounded through-only search found no end-to-end path for any of the 13 open nets.
