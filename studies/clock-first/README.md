# Populated handheld clock routing study

The complete 33-link fallback is e503b63. This branch rebuilds from the same frozen byte placement. The native assembly adds stored copper for the clock pair after the A8 phase. The next geometry group installs A6, A9, A14 and CKE. The historical data in studies/command-routing describes the fallback.

The 34-link export verified 1,043 plated barrels and 34 distinct CPU–RAM pairs. All 22 byte routes reproduced their exact vertices, widths and 44 via spans. The per-net byte timing CSV matched the frozen report byte for byte. The 0.102 mm copper, 0.1524 mm via-edge, drill spacing, self-contact, four-layer exported strokes, full-width reference and MMC0 sequenced card checks passed. The integrated CAM found no shorts between mapped land nets. It still found 54 nets with separate islands. CPU DDR supply reached 7/7 balls and 22/22 bypasses on the switched rail. DRAM supply reached 18/18 balls and 14/14 bypasses on DCDC3, with 21/21 memory returns on main ground. The two feeds remained isolated.

Both clock conductors transition L1–L4–L1. CK measures 38.67728 mm and CKn 38.65690 mm, a 0.02038 mm difference against the 0.127 mm TI pair limit. Both fit the 36.14999–38.68999 mm placement window. CK has just 0.01271 mm of upper-window headroom. Signed pair skew is +0.181 ps for CK and −0.181 ps for CKn on the reference model. Each has 2.840 mm of contacted barrel. The 0.42 mm center-distance sensitivity identifies 34.953 mm of CK and 35.367 mm of CKn near its mate. Coupling and impedance at the actual launches still need qualification.

[Per-net timing and open connections](timing.csv) compares this board with e503b63. The signed command delay is relative to the mean CK arrival. Outer traces use the existing single-ended/odd-mode reference rates. Inner traces use a separate illustrative homogeneous Dk of 4.0, equivalent to 6.671 ps/mm. Via depth uses the 1.491 mm reference stack. The command placement window is a planar screen. Simply adding barrel length to planar length puts the clocks over the upper window by 2.827 and 2.807 mm. Receiver timing needs launch uncertainty, package and dielectric corners, slew and loading. VREF, calibration, final receiver timing and system power-up remain fabrication holds.

Reproduce the timing table with `python studies/clock-first/measure.py dist/index.circuit.json <e503b63-native-board>` after the normal build. The script fails on clock window or pair mismatch.
