## MMC0 boot and DDR initialization

Pixel Dash specifies a 24 MHz oscillator and a fitted SYSBOOT word of 0x4017. The intended first boot device is MMC0. On ca10e34 eight CPU strap taps are still open. The ROM device selection cannot establish the DDR clock or pin drive configuration. The repository contains no Pixel Dash SPL board target, executable MLO, or executed DDR register trace. An actual pad launch time therefore remains unknown. [Drilled strap connectivity](drilled-cam.txt) · [TI AM335x TRM, chapters 7, 9 and 26](https://www.ti.com/lit/ug/spruh73q/spruh73q.pdf)

TI U-Boot at 70800b68682ddc7a9e7e6695712a94fc9f62ed37 selects a 400 MHz configuration for PocketBeagle or BeagleBone Black board identity. The unrecognized-board branch selects the 266 MHz DDR2 configuration. A Pixel Dash port must select its own DDR3L profile before external memory access. The reference calls the DDR PLL setup, calibrates VTP, programs three command macros and two data macros, writes the I/O controls, hands CKE to the PHY, and configures the EMIF PHY, timings and SDRAM. [Reference board selection](https://github.com/TexasInstruments/ti-u-boot/blob/70800b68682ddc7a9e7e6695712a94fc9f62ed37/board/ti/am335x/board.c) · [Initialization order](https://github.com/TexasInstruments/ti-u-boot/blob/70800b68682ddc7a9e7e6695712a94fc9f62ed37/arch/arm/mach-omap2/am33xx/emif4.c)

The TI reference writes 0x18B to all five I/O registers, 0x80 to each command slave ratio, and zero to each clock inversion register. At 400 MHz, 128/256 of a period is 1250 ps of programmed DLL shift. Actual pin-to-pin launch phase also depends on the PHY, package and operating corner. Capture those write-only ratio and inversion writes in SRAM-resident SPL, along with the clock configuration. The TI timing and data-ratio constants are for MT41K256M16HA. Pixel Dash uses a single-rank, 1 GiB MT41K512M16VRP TwinDie with 16 row, 10 column and three bank address bits. Derive EMIF addressing, refresh and timing from the fitted part and validate the full address range and both byte lanes.
